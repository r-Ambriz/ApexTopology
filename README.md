# ApexTopology

** Nokia SR OS Configuration Generator for ContainerLab**

Version: 0.2.0

## Features

- 🤖 AI-Powered configuration generation
- 🎯 SR OS 25.10.R3 native support  
- 🔧 Complete protocol support (OSPF, ISIS, BGP, LDP, RSVP-TE)
- 🎨 VSCode dark theme
- 📦 ContainerLab ready

## Quick Start

1. Open the app in your browser
2. Click NODES tab → Add nodes
3. Click LINKS tab → Connect nodes
4. Click GENERATE CONFIGS
5. Download your SR OS configs
